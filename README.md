# Φ Camera — 黄金比カメラ

iPhone の Safari で使える静的 Web カメラです。撮影枠と保存する JPEG は縦向きの黄金比（幅:高さ＝1:1.618）です。黄金矩形を正方形に分割し、各正方形の四分円をつないだガイドを初期表示します。外側の線は右下の角につながります。グリッドにも切り替えられます。ガイドはプレビュー専用で、保存する写真には入りません。前後カメラの切替にも対応し、画像は端末内だけで処理します。iPhone 12 以降の画面幅に合わせて表示が変わります。

ズームは iPhone 12 以降も含め、機種名を固定せず実行中のカメラが公開する倍率に合わせます。カメラのズーム機能をブラウザから操作できない場合は、プレビューと保存する写真を同じ範囲で切り抜く 1〜3 倍のデジタルズームに切り替えます。広角レンズへの 0.5 倍切替は、実際にブラウザが対応範囲を公開した場合にのみ使えます。

## 使い方

1. HTTPS で公開した URL を iPhone の Safari で開きます。
2. 「カメラを起動」を押し、カメラへのアクセスを許可します。
3. ガイドを選び、シャッターを押します。
4. プレビューの「写真を共有・保存」を押し、iPhone の共有画面で「画像を保存」を選びます。共有機能が使えない場合は「ダウンロード」から保存できます。

## GitHub Pages で公開

このフォルダのファイルを GitHub リポジトリのルートに置き、リポジトリの **Settings → Pages → Build and deployment** で **Deploy from a branch / main / /(root)** を選びます。公開 URL は `https://<ユーザー名>.github.io/<リポジトリ名>/` です。GitHub Pages の HTTPS がカメラ使用に必要です。

## ローカル確認

`python3 -m http.server 8000` をこのフォルダで実行し、`http://localhost:8000` を開きます。iPhone での確認には HTTPS で公開してください。

外部ライブラリ、ビルド手順、サーバーは不要です。
